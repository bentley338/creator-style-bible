# Style-Bible Checklist

Copy this checklist into the check report for every job. Tick only what has been verified, not what was assumed.

## Visual
- [ ] Colors match the style-bible
- [ ] Outline and font match the style-bible
- [ ] No banned watermark or label

## Language
- [ ] Hook is strong at the start and specific
- [ ] No banned phrases
- [ ] Caption ends with a question, if that is the user's rule

## Facts
- [ ] Every number and claim is verified or flagged as not yet verified
- [ ] No new facts added without confirmation

## Repetition
- [ ] Topic has not been used before
- [ ] Title has not been used before
- [ ] No animation repeated back-to-back
- [ ] Any spaced repetition is honestly reported

## Publishing
- [ ] Package handed over for check-first review
- [ ] Not published before the user says OK
- [ ] Backup of the finished stage saved
